Mode live dan token valid

Proses bot tetap berjalan

run_bot sudah menyertakan worker notifikasi lokal; koneksi internet diperlukan.

Akun tertaut dan setuju

04 / SISTEM & NOTIFIKASI

Privasi dibangun ke dalam alur layanan.

Kontrol aplikasi harus dilengkapi kebijakan dan disiplin operasional institusi.

Akses sesuai kebutuhan

Login dan penugasan diperiksa di server. Pelaksana tidak mendapat akses lintas lokasi atau berkas yang belum dikirim.

Bukti tidak dibuka publik

Gambar disimpan privat, diproses ulang, dan diberikan melalui endpoint terautorisasi dengan pembatasan cache.

Jejak tindakan

Perubahan data, penugasan, status dan pengarsipan tercatat. Catatan internal dipisahkan dari pesan progres pemohon.
Disediakan aplikasi: persetujuan berversi, CSRF, pembatasan percobaan tertentu, sanitasi error dan penyamaran NIK pada ringkasan bot.
Wajib disiapkan pengelola: HTTPS, kunci rahasia, backup terenkripsi, aturan retensi, akses perangkat dan prosedur insiden.

Menjalankan aplikasi di VS Code.

Operasional lokal menggunakan dua terminal pada folder yang berisi manage.py.
TERMINAL 1 · DASHBOARD

Server web

.\.venv\Scripts\python.exe manage.py runserver

Buka dashboard lokal di
http://127.0.0.1:8000.

TERMINAL 2 · BOT + NOTIFIKASI

Layanan Telegram

.\.venv\Scripts\python.exe manage.py run_bot

Bot sekaligus memeriksa antrean notifikasi lokal di latar belakang.

Sebelum menjalankan: pasang requirements.txt → isi .env → migrate → buat Superadmin → bootstrap_manager.
Komputer, internet dan kedua proses perlu tetap aktif. Saat memperbarui aplikasi, cadangkan database; pertahankan .env dan data lokal. Server lokal bukan layanan 24 jam otomatis.

Menuju operasional yang selalu tersedia.

Rancangan produksi memerlukan server terkelola; tidak bergantung pada VS Code yang dibuka di komputer petugas.

Lapisan web

Domain dan HTTPS → reverse proxy → Gunicorn / Django. Matikan debug, batasi host dan jalur akses aplikasi.

Lapisan proses

Process manager menjaga web, satu bot poller per token, serta worker notifikasi. Worker dapat dipisah untuk produksi.

Lapisan data

PostgreSQL, koneksi aman, akses terbatas, backup terenkripsi, uji pemulihan dan pemantauan kapasitas bukti.
Biaya perlu dihitung: Telegram Bot API standar tidak menagih per pesan, tetapi server, domain, penyimpanan dan koneksi operasional dapat menimbulkan biaya.

5
